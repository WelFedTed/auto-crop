# Name check: "Auto Crop" (ROADMAP M0.28)

**Status: PARTIAL, not a clearance.** This is not legal advice. It records what a web search could and could not show on 2026-10-01.

## What was done

Three general web searches (USPTO, EUIPO/TMview, and known uses of the phrase). The official registries (USPTO Trademark Search, EUIPO TMview) are interactive applications that a web search cannot query, so **no registry search was actually performed**. M0.28 therefore stays open until the owner (or the agent with registry access) runs the two searches below and appends the hits.

## What the searches found

- No registry record for "Auto Crop" surfaced (this proves nothing, see above).
- The phrase is used descriptively by others: Microsoft 365 has an **Auto Crop** command (Picture Format > Auto Crop in Word, Excel and PowerPoint, Mac 16.76 and later), and Apple Photos has an **Auto** crop/straighten button. This is generic use of a plain description of the function.

## Assessment

"Auto Crop" is a descriptive name for an automatic cropping tool. That makes it hard to protect as a trademark and weak against others, but it also means it is unlikely to infringe a narrower mark. The practical risks are (a) confusion with the Microsoft 365 command name and (b) an existing store listing with the same title. ADR-0001 already pairs the name with a tagline to reduce both.
